# Mystery Detective 🔎

A simple Java console-based mystery detective game where the player investigates a case, analyzes clues, questions suspects, and tries to identify the culprit.

## Features

- Interactive console-based gameplay
- Multiple suspects
- Mystery clues and statements
- Detective-style investigation
- Simple Java logic
- Beginner-friendly Java project

## Technologies Used

- Java
- OOP Concepts
- Collections
- Conditional Statements
- Loops
- Scanner for user input

## How to Run

1. Clone the repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the Java files.
4. Run the main class.
5. Follow the instructions shown in the console.
